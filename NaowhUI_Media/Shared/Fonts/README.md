# Fonts not included

The NaowhUI fonts are not redistributed here because their licenses belong to their
foundries, not to this port.

Copy these four files from the official **NaowhUI_Media** addon
(<https://github.com/naowh-gaming/NaowhUI>, or the NaowhUI download on CurseForge/Wago) into
this folder:

- `GothamNarrowUltra.ttf`
- `GothamNarrowUltraAsia.ttf`
- `Naowh.ttf`
- `NaowhAsia.ttf`

Add them before running `/nui install`. Without them, text set to the "GothamNarrowUltra" or
"Naowh" fonts may not render.
